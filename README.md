# universal-exploded-view-prompt

一个面向小白的“万物拆解”图片提示词 Skill：把一件商品先锁定为同一个对象，再规划完整主体、组成部件、细节放大、作用说明、使用场景和电商资产。

## 适用场景

- 想把商品做成结构说明图、详情页卖点图或商品主图
- 想让同一件商品在不同图片里保持轮廓、颜色、材质和部件数量一致
- 不知道怎样写图生图提示词，希望得到一套能复制的流程

## 安装

把本目录复制到你的 Agent skills 目录，目录名保持为 `universal-exploded-view-prompt`。不支持 Skill 的工具也可以直接打开 `SKILL.md` 当作提示词手册。

## 快速使用

把实物图、版式参考图和真实商品资料分开说明，然后告诉助手：

1. 商品是什么，准备发布主图还是详情页；
2. 选择五种风格中的一种；
3. 列出只允许出现的可见部件；
4. 写清每个部件的作用、对应位置和适用场景；
5. 生成后按验收清单逐项检查。

## 文件

- `SKILL.md`：完整流程、模板、负面约束和验收规则
- `references/ecommerce-style-library.md`：五种电商视觉风格
- `examples/`：两个从事实边界到提示词的完整示例

## 示例与边界

本 Skill 会把没有资料支持的隐藏结构标为概念示意，不会把模型猜出的尺寸、容量、材质、性能或认证写成商品事实。图片中的中文通常建议后期排版，发布前请逐字校对。
