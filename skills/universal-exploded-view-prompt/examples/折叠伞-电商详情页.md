# 折叠伞｜电商详情页示例

## 资产规划

1. 商品主图：完整收纳状态或打开状态，纯净目录风，少文字。
2. 结构卖点图：只拆可见的伞面、伞骨、中棒、手柄、伞带和收纳袋。
3. 场景图：通勤、旅行和雨天步行，场景只表达使用地点。
4. 使用养护图：打开、收拢、晾干和收纳四步。

## 提示词

使用提供的折叠伞对象参考图作为唯一商品身份真源。保持同一把伞的颜色、伞面纹理、伞骨数量、手柄形状和收纳袋比例不变。模式：电商详情页结构卖点图，4:5 竖幅，高级编辑风。画面先放完整打开的伞，再沿一条水平轴分离伞面、伞骨、中棒、手柄、伞带和收纳袋；每个部件预留中文文字槽位，逐字写入“伞面”“伞骨”“中棒”“手柄”“伞带”“收纳袋”，并分别预留“作用”和“使用场景”两行说明。补充伞面边缘、开合按钮、手柄握持处三个局部特写。商业留白干净，文字放在安全区，手机端可读。只使用用户提供或参考图可见的卖点，禁止写防水等级、抗风等级、尺寸、材质牌号、认证、价格、评价或促销词。
